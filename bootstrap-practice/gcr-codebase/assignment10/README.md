# Assignment 10 — Bootstrap

This package contains all 10 questions separately, with one HTML file and one CSS file for each question.

## Structure
- q1-company-landing
- q2-portfolio
- q3-product-catalog
- q4-restaurant-menu
- q5-blog
- q6-notifications
- q7-task-tracker
- q8-pricing
- q9-pagination
- q10-travel

Each HTML page uses Bootstrap 5 through CDN and is responsive.

Open each `index.html` in a browser. An internet connection is required for Bootstrap CDN and external images/fonts.
