How to run
----------
1. Install Node.js if it is not already installed.
2. Extract this ZIP file.
3. Open a terminal in the extracted folder.
4. Run any question independently, for example:

   node Q1_Student_Result_Processing.js

5. Repeat with the filename of another question.

Notes
-----
- Each question is in a separate JavaScript file.
- Every JavaScript filename is unique.
- The examples use standard JavaScript and can run in Node.js.
- Q1 uses these grade ranges: A = 90+, B = 75-89.99, C = 50-74.99, F = below 50.
- Q5 uses a sample fare formula: Rs. 40 base fare + Rs. 12 per kilometre.
- Q6 considers stock below 5 units to be low stock.
