# Assignment 7 - JavaScript DOM Projects

This archive contains nine independent mini-projects.

## How to run
1. Extract the ZIP archive.
2. Open a question folder (Q1 through Q9).
3. Open `index.html` in a modern web browser.
4. The folder contains its own `style.css` and `script.js`.

No frameworks or external packages are used. Q5 loads sample images from picsum.photos and therefore needs an internet connection.
