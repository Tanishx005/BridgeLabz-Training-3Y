Responsive Design Principles

Three core ideas for adaptable interfaces.

Fluid Layouts

A fluid layout uses flexible dimensions so content expands or shrinks with the viewport.

width: 100%;
max-width: 1200px;

Flexible Media

Images should scale inside their containers without overflowing.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Media queries introduce layout changes at useful screen widths.

@media (max-width: 600px) {
  .layout { ... }
}
