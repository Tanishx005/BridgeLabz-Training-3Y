Responsive CSS Cheat Sheet

Quick references for common responsive techniques.

Filters

Example: filter: grayscale(100%);

Changes visual appearance of elements.

Media Queries

Example: @media (max-width:700px)

Applies styles based on viewport conditions.

Responsive Design

Example: width:100%;

Allows layouts to adapt to screen sizes.

Typography

Example: font-size:clamp(...);

Keeps text flexible and readable.

Flexbox

Example: display:flex;

Aligns and distributes items.

Grid

Example: display:grid;

Builds row and column layouts.
