How a Browser Requests and Displays a Web Page

  1. Enter the website URL in the browser.
  2. DNS resolves the domain name to an IP address.
  3. The browser sends an HTTP/HTTPS request.
  4. The web server processes the request.
  5. The server returns the requested response/resources.
  6. The browser parses and renders the page for the user.

Flow: URL → DNS → Request → Server → Response → Browser Rendering
